# Daily Briefing

Produce one short, skimmable message. Lead with what needs Matt today. This is what makes
the hub feel like a second brain instead of an app to check.

## Steps

1. **Time frame** — morning briefing (looking forward) or evening wrap (looking back).
   Read `brain/50-system/cadence.md` for the active schedule.

2. **Gather in parallel** (delegate or read directly):
   - **Calendar** (Chronos → `list_events`): today's meetings, conflicts, gaps.
   - **Inbox** (Hermes): the "Needs Matt" bucket + any customer-need signals.
   - **Pipeline** (`brain/20-work-pipeline/` + Vantage): moves, overdue follow-ups, hot leads.
   - **People** (`brain/10-people/`): relationships due for a touch.
   - **Signals** (Hermes digest in `brain/50-system/signals/`): only if something's worth acting on.
   - **Games** (`brain/40-games/`): sessions/events/guild items due.

3. **Rank by "does this need Matt today?"** Top of the message = decisions and time-sensitive
   items. Everything else compressed below.

4. **Format** (keep it tight):
   ```
   ☀️ Morning, Matt — {date}

   NEEDS YOU
   • …

   TODAY
   • {calendar}

   PIPELINE
   • {moves + follow-ups due}

   PEOPLE
   • {who to reach out to}

   FYI
   • {signals / games / low-priority}
   ```
   Evening wrap swaps to: DONE / STILL OPEN / TOMORROW.

5. **Persist** the briefing date + anything newly promised into the brain so nothing
   repeats or drops.

## Output
The finished briefing text, ready for Atlas to send.
