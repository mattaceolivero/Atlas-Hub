# Games & Community 🎲

Bard's domain. Suggested layout — create folders as your worlds grow:

```
40-games/
  dnd-dm/
    {campaign-name}/
      world.md          # setting, factions, lore
      npcs/             # one note per NPC, [[linked]]
      party.md          # the players' characters
      sessions/         # dated recaps: 2026-07-03-session-12.md
      threads.md        # open plot threads
      prep-next.md      # prep pack for the upcoming session
  dnd-play/
    {campaign-name}/
      my-character.md
      recaps.md
      goals.md
  mtg/
    decks/              # one note per deck: list + strategy
    collection.md
    wants.md
  discord-guild/
    overview.md         # what the guild is, health, goals
    events.md           # upcoming + past events
    members.md          # notes (link to [[10-people]] where they overlap)
    announcements/      # drafts Matt posts
```

Continuity is the whole point: every session and event becomes a dated, wikilinked note
so each world reads like a living wiki. People who are also friends link back to
`[[10-people/...]]` so Hestia and Bard share one graph.
